サクガワAI会社

ホームプライバシーポリシー

考えをつなぎ、やりたいことを、一つずつ形に。

サクガワAI会社は、YouTubeチャンネル「38歳一般人が有名になって西武ライオンズの始球式を目指す」を運営する本人が、自分の活動を整理し、次の一歩を決めるために使っている個人用の業務アプリです。

このアプリでしていること

  • 本人のMacの中だけで動き、本人だけが使います。一般の利用者向けのサービスではありません。
  • 本人のYouTubeチャンネルの実績（登録者数・再生数・視聴時間など）を、YouTube API サービスから読み取り専用で取得し、画面に表示します。
  • その実績をもとに、AIの秘書（Anthropic社のClaude）が、動画の企画や振り返りの相談に乗ります。
  • 動画の投稿・変更・削除など、YouTubeへの書き込みは一切行いません。

データの扱い

取得したデータの扱いは、プライバシーポリシーに記載しています。
