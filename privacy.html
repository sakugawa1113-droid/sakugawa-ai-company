プライバシーポリシー

制定日：2026年10月27日

サクガワAI会社（以下「本アプリ」）は、運営者本人が自分の活動のために、本人のMac上で使用する個人用の業務アプリです。本アプリは YouTube API サービスを利用しています。本アプリを利用することで、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。

1. 利用者

本アプリを使うのは運営者本人だけです。第三者のアカウントやデータを取得することはありません。

2. 取得する情報

本人が Google アカウントで許可した場合に限り、YouTube API サービスから次の情報を読み取り専用（youtube.readonly・yt-analytics.readonly）で取得します。

  • 本人のチャンネルの名前・登録者数・総再生数・動画数
  • 本人のチャンネルの動画のタイトル・公開日時・長さ
  • 再生数・総再生時間・平均視聴時間・平均視聴率・高評価数・登録者の増減などの集計値

視聴者一人ひとりを特定できる個人情報は取得しません。

3. 使い道

  • 本アプリの画面に、本人のチャンネルの実績として表示します。
  • 本人が相談したときに、AI の秘書（Anthropic 社の Claude）へ、相談に必要な範囲の実績（集計値と動画タイトル）を渡し、企画や振り返りの助言を作ります。Anthropic 社によるデータの扱いは Anthropic のプライバシーポリシーをご覧ください。
  • 本人が操作したときに限り、実績の要約を本人のメモ（ノート）に記録します。

上記以外の目的には使いません。広告・販売・第三者への提供は一切行いません。

4. 保存と安全管理

  • 取得した情報と認証情報（アクセストークン等）は、本人のMacの中にだけ、本人だけが読める設定で保存します。
  • 認証情報は画面・記録・外部サービスに表示・送信しません（Google への認証のための通信を除く）。
  • 通信は Google の決められた宛先にだけ、暗号化（HTTPS）して行います。

5. 許可の取り消しとデータの削除

  • 本アプリの「接続を解除」で、Google への許可を取り消し、保存した認証情報を削除できます。
  • Google アカウントのセキュリティ設定（サードパーティのアクセス）からも、いつでも許可を取り消せます。
  • 本アプリに保存した実績のデータは、本人がMacから削除できます。
